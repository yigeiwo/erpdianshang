# 电商ERP系统 - 项目概述

## 项目信息

- **项目名称**: 电商ERP系统 (E-Commerce ERP System)
- **版本**: v1.0.0 (规划中)
- **创建日期**: 2026-04-23
- **技术栈**: Node.js (NestJS) + React + PostgreSQL

## 1. 项目愿景

打造一个功能完善、可扩展的电商企业资源规划系统，涵盖采购、销售、库存、财务、数据分析等核心业务模块，支持多数据源整合（API + 爬虫），为宜家式的电商企业提供数字化运营能力。

## 4. 技术选型

### 后端
- **框架**: NestJS
- **ORM**: TypeORM
- **数据库**: PostgreSQL
- **认证**: JWT + Passport
- **验证**: class-validator
- **任务调度**: @nestjs/schedule

### 前端
- **框架**: React 18
- **UI库**: Ant Design 5
- **状态管理**: Zustand / Redux Toolkit
- **路由**: React Router 6
- **图表**: ECharts / Ant Design Charts
- **HTTP**: Axios

### 基础设施
- **容器化**: Docker + Docker Compose
- **Web服务器**: Nginx
- **缓存**: Redis (可选)

## 7. 约束与原则

1. **模块化设计**: 各模块独立开发、测试、部署
2. **API优先**: 先定义接口，后实现
3. **文档驱动**: 重要决策需记录文档
4. **测试覆盖**: 核心业务逻辑需有单元测试
5. **代码规范**: 遵循 ESLint + Prettier 规范
